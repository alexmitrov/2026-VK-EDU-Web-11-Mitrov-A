# AskBrains

## Запуск проекта

### Вариант 1: Локальный запуск

0. Склонируйте данный репозиторий и перейдите в директорию ask\_brains
```bash
cd ask_brains
```

1. Создайте и активируйте виртуальное окружение:
```bash
python -m venv venv
source venv/bin/activate
```
2. Установите зависимости:
```bash
pip install -r ../requirements.txt
```

3. Запустите
```bash
python manage.py runserver
```

4. Откройте браузер и перейдите по адресу 127.0.0.1:8000

5. Для остановки выполните Ctrl + C

### Вариант 2: Docker

0. Склонируйте репозиторий

1. Соберите и запустите контейнер
```bash
docker compose up --build
```

2. Откройте браузер и перейдите по адресу 127.0.0.1:8000

3. Для остановки выполните Ctrl + C
